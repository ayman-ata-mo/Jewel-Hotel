نسخة جويل فندق التجريبية 6.03.03 لموقع GitHub Pages
ارفع محتويات هذا المجلد مباشرة إلى جذر مستودع Jewel-Hotel.
تسجيل الدخول: demo / demo
البيانات الوهمية محفوظة في localStorage داخل المتصفح، ولا تتزامن بين الأجهزة.
لإعادة البيانات الأصلية افتح أدوات المتصفح وامسح بيانات الموقع، أو نفذ jewelDemoReset() في Console.
زر طباعة فاتورة متاح بجانب كل حجز وفي صفحة الحجوزات.
هذه نسخة اختبار فقط ولا تستخدم PHP أو MySQL ولا تستقبل مدفوعات حقيقية.


تحديث توزيع الغرف: 26 غرفة، الدور الأول 1001-1006، الثاني 2001-2010، الثالث 3001-3010.
تم تعديل شاشة تعديل الحجز وإضافة حفظ وطباعة إيصال.
البيانات التجريبية الموجودة جرى تحويل أرقام غرفها وحذف الحجوزات المرتبطة بغرف خارج التوزيع الجديد.
هذه حزمة GitHub Pages استعراضية؛ لا تُعد برنامج Windows EXE ولا تحتوي خادم PHP أو قاعدة بيانات تشغيل حقيقية.


تحديث بيانات الغرف: نسخة 6.03.04 تستخدم مفتاح تخزين جديد للعرض، بحيث تتجاهل بيانات الغرف القديمة المحفوظة بالمتصفح وتحمّل demo-data.json الذي يحتوي على 26 غرفة في 3 أدوار. بعد التحديث، أي بيانات تجريبية سابقة مخزنة في المتصفح لن تظهر؛ البيانات القديمة لا تُحذف فعليًا من المتصفح.
